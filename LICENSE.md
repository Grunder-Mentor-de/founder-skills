# Nutzungsbedingungen für die kostenlosen Founder Skills

Stand: Oktober 2026. Entwurf, rechtlich nicht geprüft.

Die Founder Skills in diesem Repository sind urheberrechtlich geschützt. Rechteinhaber ist Michael Detke, Gründer-Mentor.de. Dass das Repository öffentlich ist, macht die Inhalte nicht frei verwendbar.

## Das darfst du
- Die Founder Skills für dein eigenes Vorhaben nutzen, privat und beruflich, auch in deinem Startup.
- Sie für dich oder dein Team anpassen.
- Ergebnisse, die du mit den Skills erarbeitest (One-Pager, Pitch, Präsentationen, Nachrichten), frei verwenden. Sie gehören dir.
- Den Link auf dieses Repository teilen, mit wem du willst.
- Das Repository auf GitHub forken, soweit die Nutzungsbedingungen von GitHub das für öffentliche Repositories vorsehen, und Änderungen über Issues und Pull Requests vorschlagen.

## Das darfst du nicht
- Die Founder Skills oder angepasste Fassungen davon verkaufen oder in bezahlte Angebote einbauen, zum Beispiel in Kurse, Beratung oder Software.
- Sie außerhalb von GitHub als eigene Sammlung weiterverbreiten, etwa auf Marktplätzen für Skills, in Foren oder sozialen Netzwerken. Teile stattdessen den Link.

## Beiträge
Wenn du einen Vorschlag oder Pull Request einreichst, darf Michael Detke ihn in die Founder Skills übernehmen, anpassen und unter diesen Bedingungen weitergeben.

## Keine Beratung
Die Founder Skills ersetzen keine Rechts-, Steuer- oder Finanzberatung. Die Inhalte beruhen auf persönlichen Erfahrungen und gelten nicht für jeden Fall.
