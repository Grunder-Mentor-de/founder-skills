# Vorlage: Livegang-Protokoll

Fülle nur mit dem, was die Person gesagt hat. Was fehlt, steht als „offen“ da. Deine eigenen Einschätzungen beginnen mit „Einschätzung:“. Ein Punkt der Prüfliste ist erst „erledigt“, wenn die Person ihn bestätigt hat. Halte das Protokoll auf etwa zwei Seiten, Tabellenzellen höchstens etwa zehn Wörter.
