# Impressum, Datenschutz und Kontaktweg

Lies diese Datei in Schritt 1 (Abschnitt „Kontaktweg“) und in Schritt 5. Sie beschreibt die Rechtslage in Deutschland mit Stand 10/2026 (abgerufen am 15.10.2026). Sie ist allgemeine Information, keine Rechtsberatung. Du berätst nicht im Einzelfall: Fragen zur eigenen Lage der Person notierst du als offenen Punkt und verweist auf einen Generator für Rechtstexte, die IHK oder eine Anwältin oder einen Anwalt. Liegt die Person außerhalb Deutschlands, sag, dass diese Datei nicht passt.

## 1. Impressum

Pflicht für „geschäftsmäßige, in der Regel gegen Entgelt angebotene digitale Dienste“ nach § 5 Digitale-Dienste-Gesetz (DDG, seit 14.05.2024, ersetzt das Telemediengesetz). Einschätzung: Eine Firmenseite fällt in der Regel darunter, auch vor dem ersten Umsatz. Im Zweifel ein Impressum angeben und die Frage als offenen Punkt notieren. Die Angaben müssen leicht erkennbar, unmittelbar erreichbar und ständig verfügbar sein, deshalb der Link im Fuß jeder Seite.

Tabelle zum Ausfüllen, angepasst an die Person (Zeilen, die nicht zutreffen, streichst du):

| Angabe | Wann nötig | Antwort |
|---|---|---|
| Name, bei Firmen Name der Firma mit Rechtsform | immer | |
| Anschrift, unter der man Post zustellen kann | immer | |
| Vertretungsberechtigte Person | bei GmbH, UG und anderen juristischen Personen | |
| E-Mail-Adresse | immer | |
| Weiterer Weg zur schnellen, unmittelbaren Kommunikation, etwa Telefon | § 5 verlangt schnelle elektronische Kontaktaufnahme und unmittelbare Kommunikation. Ob dafür ein Telefon nötig ist, im Einzelfall klären | |
| Register und Registernummer | wenn im Handelsregister eingetragen | |
| Umsatzsteuer-Identifikationsnummer | wenn vorhanden | |
| Aufsichtsbehörde | bei zulassungspflichtiger Tätigkeit | |
| Kammer, Berufsbezeichnung, Berufsregeln | bei reglementierten Berufen | |
| Verantwortlicher für redaktionelle Inhalte (§ 18 Abs. 2 MStV) | wenn die Seite einen Blog oder journalistische Texte hat | |

- Bei Teams, die gemeinsam ohne Firma auftreten, gehören alle Gründerinnen und Gründer ins Impressum. Ob das im Einzelfall so ist, klärt die Person mit Fachleuten.
- Wer keine Geschäftsadresse hat, sollte wissen, dass die Anschrift öffentlich ist. Lösungen (Geschäftsadresse, Coworking, Gründerzentrum) sind ein offener Punkt für die Person, keine Empfehlung von dir.

## 2. Datenschutzerklärung

Art. 13 DSGVO verlangt Informationen, sobald personenbezogene Daten verarbeitet werden. Beim Besuch einer Seite auf GitHub Pages speichert GitHub laut eigener Doku die IP-Adresse jedes Besuchers zu Sicherheitszwecken. Eine Speicherdauer nennt GitHub nicht.

In die Datenschutzerklärung gehören bei einer Seite nach `references/bauen.md` mindestens:
- wer verantwortlich ist, mit Kontakt
- Hosting bei GitHub (GitHub, Inc., USA), welche Daten (IP-Adresse, Zugriffsdaten), Zweck (Sicherheit, Betrieb), Rechtsgrundlage
- Übermittlung in die USA: GitHub ist laut eigener Angabe unter dem EU-U.S. Data Privacy Framework zertifiziert
- Speicherdauer, soweit bekannt
- der gewählte Kontaktweg und was mit Nachrichten passiert
- die Rechte der Besucher (Auskunft, Berichtigung, Löschung, Einschränkung, Widerspruch, Beschwerde bei einer Aufsichtsbehörde)

Was offen ist und die Person mit Fachleuten klärt:
- Ob ein Vertrag zur Auftragsverarbeitung mit GitHub nötig ist. Für kostenlose Konten ist keiner belegt. Das Bayerische Landesamt für Datenschutzaufsicht hat 2018 geschrieben, dass das Hosting einer statischen Seite zur Selbstdarstellung ohne Tracking keine Auftragsverarbeitung ist. Ob das heute noch gilt, ist nicht geprüft.
- Eine Aussage einer Behörde speziell zu GitHub Pages für Firmenseiten wurde nicht gefunden.

Liegt die Seite bei Hostinger, ersetzt Hostinger GitHub in dieser Liste. Was zu Vertrag und Serverstandort bekannt ist, steht in `references/hostinger.md`, Abschnitt 3.

Empfehlung: die Datenschutzerklärung mit einem Generator für Rechtstexte erstellen und dabei GitHub als Hoster und den Kontaktweg angeben, oder sie prüfen lassen.

## 3. Cookie-Banner

- § 25 TDDDG (früher TTDSG): Eine Einwilligung braucht es, wenn etwas im Endgerät gespeichert oder ausgelesen wird, das nicht unbedingt nötig ist. Das gilt auch für `localStorage` und Ähnliches.
- Die Datenschutzkonferenz schreibt, Banner sollen nur dort stehen, wo wirklich eine Einwilligung nötig ist.
- Eine Seite nach `references/bauen.md`, ohne Cookies, ohne Speichern im Browser und ohne eingebundene fremde Inhalte, braucht danach kein Banner. Das ist ein Umkehrschluss, kein ausdrücklicher Satz im Gesetz.
- Eingebundene Schriften, Skripte, Karten oder Videos von fremden Servern übermitteln laut Datenschutzkonferenz regelmäßig Daten. Das Landgericht München I hat am 20.01.2022 (3 O 17493/20) einem Besucher 100 € Schadensersatz zugesprochen, weil eine Seite Google Fonts von Google-Servern geladen hat. Deshalb Schriften selbst hosten.

## 4. Kontaktweg

Standard in diesem Skill ist der erste Weg: Der Hauptknopf löst ein Gespräch aus. Die anderen beiden nur, wenn die Person sie will.

| Weg | Vorteil | Nachteil |
|---|---|---|
| E-Mail-Adresse mit `mailto:`-Link und vorbelegtem Betreff (`mailto:name@domain.de?subject=Anfrage%20Erstgespr%C3%A4ch`, Umlaute und Leerzeichen kodiert) | kein Zusatzdienst, nichts Neues in der Datenschutzerklärung außer dem Umgang mit Nachrichten | öffnet ein Mailprogramm, das manche am Rechner nicht eingerichtet haben. Die Adresse steht sichtbar auf der Seite |
| Link zu einem Terminkalender | ein Klick zum Gespräch, passt zum Ziel „Termin vereinbaren“ | eigener Dienst, eigener Abschnitt in der Datenschutzerklärung, oft mit Sitz außerhalb der EU |
| Formulardienst | Nachricht ohne Mailprogramm | GitHub Pages kann Formulare nicht selbst verarbeiten. Eigener Dienst, eigener Abschnitt in der Datenschutzerklärung, Vertrag zur Auftragsverarbeitung prüfen |

Worauf die Person bei einem Formulardienst achtet:
- Sitz und Datenverarbeitung in der EU
- ein Vertrag zur Auftragsverarbeitung, den man abschließen kann
- funktioniert mit einer statischen Seite (Formular per HTML, ohne eigenes Skript)
- wie lange Einsendungen gespeichert werden
- Grenzen im kostenlosen Tarif

Am 15.10.2026 gab es Dienste mit Sitz in der EU und Vertrag zur Auftragsverarbeitung, aber auch verbreitete Dienste, die Daten in den USA verarbeiten und keinen solchen Vertrag nennen. Nenn keinen Anbieter als Empfehlung. Die Person prüft die Angaben selbst auf der Seite des Dienstes.

Der Kontaktweg wird in Schritt 7 mit einer Testnachricht geprüft.

## 5. Barrierefreiheit

Das Barrierefreiheitsstärkungsgesetz (BFSG) gilt seit 28.06.2025 für Dienstleistungen im elektronischen Geschäftsverkehr mit Verbrauchern, also Seiten, über die Verbraucher einen Vertrag schließen. Kleinstunternehmen (weniger als 10 Beschäftigte und höchstens 2 Mio. € Umsatz oder Bilanzsumme), die Dienstleistungen anbieten, sind ausgenommen. Reine Infoseiten fallen laut Bundesfachstelle Barrierefreiheit und Kanzleien wohl nicht darunter, eine Terminbuchung für Verbraucher womöglich schon. Das ist Auslegung, im Einzelfall klärt es die Person mit Fachleuten. Die Regeln in `references/bauen.md` (Kontrast, Schriftgröße, Alternativtexte, Zoom erlaubt) helfen unabhängig davon allen Besuchern.
