# Mitmachen

Jede Rückmeldung macht die Founder Skills besser. Du brauchst dafür keine Programmierkenntnisse, nur ein kostenloses GitHub-Konto. Ohne Konto schreibst du an kontakt@gruender-mentor.de.

## Drei Wege

1. **Rückmeldung zu einem Skill:** Am einfachsten über den Abschluss am Ende des Skills. Claude gibt dir einen Link, der das Formular [„Rückmeldung zu einem Skill“](https://github.com/Grunder-Mentor-de/founder-skills/issues/new?template=rueckmeldung.yml) mit Skill, Version, Sternen und einer neutralen Zusammenfassung vorbelegt. Du prüfst den Text und klickst auf „Create“. Ohne dein ausdrückliches Ja schickt der Skill nichts ab.
2. **Änderung vorschlagen:** Eine Frage ist unklar, ein Schritt fehlt, ein Beispiel passt nicht? Lege ein Issue mit der Vorlage „Änderungsvorschlag“ an.
3. **Neuen Skill anregen:** Welches Thema fehlt dir? Nutze die Vorlage „Neuer Skill“.

## Was mit deiner Rückmeldung passiert

- Ein Workflow liest Skill und Sterne aus dem Formular und setzt die Labels `skill:<slug>` und `sterne:<1-5>`.
- Michael liest jede Rückmeldung und arbeitet passende Vorschläge in eine der nächsten Versionen ein. Gebaut und getestet wird in einem eigenen Repository, hier erscheint nur die fertige Fassung.

## Was hier nicht hingehört

Alles in diesem Repository ist öffentlich. Deshalb keine Kundennamen, Zahlen oder Vertragsdetails aus deinem Startup und keine Daten anderer Personen, zum Beispiel aus Kundengesprächen. Beschreib das Muster, nicht den Fall.

## Pull Requests

Sind willkommen, eine Änderung pro Pull Request, mit kurzer Begründung. Michaels Erfahrungen in `references/erfahrungen.md` ändert nur Michael. Vorschläge dazu gern als Issue. Weil die Skills in einem anderen Repository entstehen, übernimmt Michael gute Vorschläge dort und schließt den Pull Request hier mit einem Hinweis auf die Version.
